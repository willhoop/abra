### The fix

`engine/medicham2-browser.js`:

- the queue build is now a function, `_queueRefills()` — byte-identical body, plus the clear — so it
  can be asked again. The first call reproduces the old behaviour exactly.
- a bounded wave loop after `refill()`. Termination is the **board**, not the cap: each wave either
  spends a bench body or finds no queued side with a live bench body left. The `8` is a backstop, so
  a future `bringIn` that refuses for a reason this loop cannot see becomes `MEDFAILS.refillWaveCapHit`
  rather than a hang. The wipe check is the authority's own `if (this.ended) return true;`.
- the `Update` pass and the `traceSweep` stay below all of it, unchanged — both idempotent over bodies
  that already had them.

Counters, both DECLARED in `MEDSEEN` (`tests/test-counter-init.js` green):
`refillSecondWave`, `refillWaveStoppedByWipe`. Stamps: `MEDFAILS.refillOneWave`,
