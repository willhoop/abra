## A line-ending hazard, caught and corrected before the gate was trusted

`docs/MEASURE.md` is a **CRLF** file; the six others are **LF**. The insertion script split and
rejoined on `\n`, which preserved each file's existing endings but wrote the newly inserted MEASURE
lines with bare LF — 56 of them, mixed into a 5,581-line CRLF file. That is the exact shape of the
2026-08-28 incident recorded in this ledger, where five gate clauses went blank on a line ending. The
file was normalised to CRLF throughout and re-verified: `bare LF before=56 after=0, CRLF=5649`, and
`git diff --stat` reads `68 insertions(+)` with no deletions — i.e. an insertion, not a whole-file
rewrite. The gate was re-run after the correction, not before.
