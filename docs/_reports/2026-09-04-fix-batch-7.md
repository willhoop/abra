**Probe:** `tests/probe_sun_refuses_freeze.js`. **Knob:** `MEDI_FRZ_IN_SUN=1`.

### WHY THIS ONE

The 40 were re-diagnosed from `fix-batch-6.json`'s own `state.first_board_divergences` before

(damage-value 7 = ROADMAP #542; VOID 7 = MEASURE; the Dire Claw sleep clock; `stall`;

**`frz` at 3 is the largest available group, and TWO of the three carry a Charizard-Mega-Y** — which

### THE AUTHORITY, READ WHOLE

`data/conditions.ts:579-582`:

```js
sunnyday: { … onImmunity(type, pokemon) {
  if (pokemon.effectiveWeather() !== 'sunnyday') return;
  if (type === 'frz') return false; }, … }
```

`desolateland` carries the byte-identical handler against its own id.
**`data/mods/champions/conditions.ts` overrides NEITHER** — it holds `par`, `slp` and `frz` and no
weather at all — so mainline is authoritative here, and establishing that is itself a derivation.

Reached from `Pokemon#setStatus` (sim/pokemon.ts:1714-1725) via `runStatusImmunity` (:2275-2295),
whose second half is `runEvent('Immunity', this, null, null, type)`.

**MEGA SOL REACHES THIS HANDLER**, which is why the weather is read through `effWeatherOf` and not off
the field. `onImmunity` calls `pokemon.effectiveWeather()` with NO argument, so `sourceEffect` falls
back to `this.battle.effect` — inside `runEvent('Immunity')` that is the sunnyday condition itself,
whose `effectType` is `'Weather'`, satisfying the Mega Sol clause at sim/pokemon.ts:2195-2202.

### WHY THIS IS A NAMED TABLE AND NOT A DERIVED TAG

`data/tags.json` tags moves, items and abilities. It carries **no conditions**, so "the sun refuses a
freeze" cannot be a tag today. This is the same shape as Electric Terrain's `onSetStatus`
(2026-09-01, `eTerrainRefusesSleepOn`) and is written the same way: the authority is cited at the
site, and the probe DERIVES the authority's table and asserts the engine's equals it. The key is the
engine's word `sun`, which is not a collapse — `tag_dex`'s own `W2ENGINE` maps both `sunnyday` and
`desolateland` onto it and the two conditions carry the identical handler.

**THE COUNTER IS ITS OWN.** `statusRefusedByWeatherCondition` is counted apart from
`statusRefusedByWeather`, which is Leaf Guard — an ABILITY whose handler happens to read the weather.
A run where one moves and the other never does is exactly the state this engine was in.
