## 3. THE IGNORE RULE IS THE ACTUAL FIX

`.gitignore` now carries `.scratch*` and `data/_scratch-*`. The 28 untracked entries were a hazard
twice over: `git add -A` swept other agents' staged files into five commits in one night, and an
untracked file is **unrecoverable**, so every tidy-up had to weigh destroying somebody's evidence
against a dirty `git status`. Ignoring the prefix ends both — the tree reads clean and nothing has to
be deleted to make it read clean. 51 files remain on disk and are invisible to `git status`.
