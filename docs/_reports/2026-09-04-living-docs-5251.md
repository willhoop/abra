## What the blocks say, and the one thing they are careful not to say

This release is the REGISTER and the COUNTERS. Every block states, in its own register, that no
mechanic changed, no differential was run and no whole-game figure was re-derived. Board-material is
carried forward, never re-earned: `data/verification/fix-batch-M6instr-defog.json` at 46 of 961 with
protocol 141, `data/game-differential.json` still at 77 of 961 and still what the gate clause prints.
Both artifacts are named in the same sentence as their figure everywhere the figure appears.

The four items named as the method are written in all eight documents, each in that document's
voice:

1. **The specified pipe repair does not work, and that was measured before anything was touched.**
   Escaping as `\|` changes nothing — the status-cell capture is a negated-pipe character class and
   stops at `\|` exactly as at `|`. Proven on a synthetic row through the shipping detectors. The
   pipes were removed instead, and the shared closed-row detector was left alone because mutation
   testing showed it can be `return true` with all 159 of its assertions still passing.
2. **The sweep found a CLASS: 98 rows, 669 unescaped pipes, 22 cut status cells, nine reading OPEN
   against an authored `closed` cell.** Reported and LEFT, because inferring a closure from a parse
   artifact is the error that started the evening. Their owners must restate them.
3. **Four `NaN` counters**, one published as `null` in `data/million-run.json` and
   `data/million-run-150k.json` — the capability fired and the counter recorded nothing, twice.
   Another declared inside the wrong object literal. **No `|| 0` at any increment site**, because
   that hides which object owns the counter and ownership was the defect.
4. **The pin guard's `wrong_release` branch was unread**, in a guard this session built hours
   earlier, whose own comment quoted the founding rule while naming five of six branches. The branch
   list is now derived from the object's keys. Selftest 216 → 218 passed, 0 failed.

Also carried everywhere it fits: `tests/test-counter-init.js` finds exactly 4 violations across 507
files and 602 counter literals with zero false positives and no exemption list, shown RED on all
four first, naming the 6 computed-key increments it cannot decide; and the correction that five
counters the audit called unread ARE read, via `Object.assign`, which a name grep cannot see.
