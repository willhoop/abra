## The citation rule, measured before writing rather than after

`engine/docs_scan.js`'s `citationsIn()` matches `data/<name>.json` only — a path with a second
slash is not a citation, so naming `data/verification/fix-batch-M5M7M8.json` does not put a block
under rule 3b(b). Naming `data/game-differential.json` does. So every paragraph that names it was
kept to figures that file actually holds (50, 77, 150, 161, 961 all verified present), and the one
draft paragraph that would have cited `data/policy-weights.json` alongside a page of engine figures
was split so the citation carries no figures at all. Uncited figures were checked against
`changelogHas` and the artifact union in advance: 50, 961, 150, 161, 77, 61, 168, 84, 81, 124, 60,
65, 66, 63, 36, 34, 62, 149, 137, 25, 210, 11, 122, 172, 244, 344, 27, 954 are all traceable.
`10608`, `10455` and `16.14` are not, and were deliberately not written.
