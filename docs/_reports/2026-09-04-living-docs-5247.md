## The caveat, written the same way in all eight

Every document states it in its own paragraph rather than inside the narrative, because the brief is
that it must travel with the number every time:

> `data/verification/fix-batch-M1M3M4.json` holds board-material **61 of 961**.
> `data/game-differential.json` is the artifact the gate clause reads; it was **not rewritten** in
> this pass and still holds **77 of 961**. Both are correctly measured on identical pins, and only
> the second is published.

Splitting it out was not only editorial. `engine/docs_scan.js`'s citation rule (3b(b)) requires every
figure in a block naming a `data/*.json` file to be present in that file, and `citationsIn()` matches
`data/<name>.json` only — a path with a subdirectory (`data/verification/…`) is not a citation at all.
Measured before writing: `data/game-differential.json` contains 77, 961, 61, 168 and 161 but does NOT
contain 829, 828 or the prediction band's upper bound. So the census figures and the prediction band
were kept out of any block naming a top-level artifact, and the same reasoning moved
`data/policy-weights.json` (MODELS) and `data/engine-diff.json` (DAMAGE-STAGES) into paragraphs of
their own that carry no figures.

Rule 3b(c) is satisfied by construction rather than by luck: `changelogHas()` treats the CHANGELOG as
a trace, and every figure written into these blocks is taken verbatim from the `## [5.247.0]` block.
Where the changelog spells a number as a word ("Sixteen games", "thirty-two batches") the documents
spell it as a word too. The prediction band is written `60–70` with the same en dash the changelog
uses, because `docs_scan.js` reads the en dash as a sign and `60-70` would not have matched.

No figure written here is distinctive enough to enter the derived retraction registry
(`isDistinctive` needs a percent at three significant figures or a value ≥ 1000), so none of these
blocks can retroactively accuse another document.
