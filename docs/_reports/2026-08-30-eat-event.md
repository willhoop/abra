## 2. THE AUTHORITY'S THREE STATEMENTS — CHAMPIONS CHECKED FIRST, EVERY TIME

- **`Pokemon#eatItem` is ONE STRAIGHT LINE** (`sim/pokemon.ts:1785-1811`), and that is the load-bearing
  fact: a road that skipped `runEvent('EatItem')` skipped everything beside it.

  ```

    singleEvent('Eat', item, …)                                  :1791       the BERRY's own effect
  ```

- **The resist berry spends the WHOLE of it inside the calculation.** `chopleberry.onSourceModifyDamage`
  (`data/items.ts`, the same body on all 18 members, Champions overrides none):
  `if (target.eatItem()) { this.add('-enditem', target, this.effect, '[weaken]'); return
  this.chainModify(0.5); }`. So the `[weaken]` line is written **after** everything `eatItem()` did —

## 3. WHAT MOVED IN THE ENGINE

`runEatItemEvent(m, itemId, fromEffect)` is the tail of `consumeBerry` lifted into its own function, so
the three roads that never call `consumeBerry` can raise the event without pretending to be one.

- **Rows 5 and 6 are routed through `consumeBerry` WHOLE**, because `eatItem` is one straight line.
  That is not tidiness — it is the difference between fixing one ability and five. On the resist-berry
  road, Cheek Pouch healed nothing, Harvest had no `lastItem` to give back, Belch stayed illegal,
  Pickup saw no spend and the partner's Symbiosis never answered. **One missing call, five mechanics.**
- **Row 7 is deliberately NOT routed through it.** Routing a flung berry through the one consumption
  site would hand the target four things the game does not give it (`lastItem`, `usedItemThisTurn`,
  a second `-enditem`, and Symbiosis).
- **The `[weaken]` line now sits below the call**, so a Cheek Pouch holder reads `B P W D` and not
  `B W D`.
- **`fromEffect` makes Cud Chew's `notFromEffects` reachable for the first time.** It was carried in the
  artifact and the old comment said it was unreachable because Bug Bite and Pluck do not come through
  `consumeBerry`. It is still unreachable, and now for a MEASURED reason (§1, row 9) rather than an
  assumed one. Fling passes `a.move.id`, which is not in the list, so Cud Chew arms off a flung berry —
  which is what the handler's own list says.
- **`curesVolatile` has three legal members and one of them is MENTAL HERB, which is not a berry.**
  Membership was printed before wiring, per LESSONS 4. Mental Herb cannot reach the confusion road
  today because its `cures` list does not contain `confusion` and `confusion` is the only volatile
  `itemCuresVolatile` is ever asked about — but "cannot today" is exactly the assumption that rots, so
  a non-berry arriving there keeps the old shape and is COUNTED (`MEDFAILS.volatileCuredByNonBerry`).
