## Research (short phase, before the build)

**Method and its limit.** WebSearch/WebFetch were not available to this agent. The phase extends the in-repo design research
(`docs/_reports/2026-09-23-solver-research-learning.md`, `-turn-search.md`, which fetched and cited the Pokémon papers) with

### 1. Value targets from search in simultaneous-move, imperfect-information games

| Work | Value target | Belief handling | What we took |
|---|---|---|---|
| AlphaZero (Silver et al., Science 2018) | the game outcome z only | none (perfect information) | — |
| Expert Iteration (Anthony, Tian, Barber, NeurIPS 2017) | the expert's (search's) evaluation or z; the apprentice imitates the expert | none | the loop shape: label with a stronger search than the one that played |
| "Lessons from AlphaZero, part 4" (Young, Prasad, Abrams, Oracle, 2019) [recalled] | averaging z with the root value q ("(z + q)/2") trained better than z alone in a small-compute Connect Four reproduction | none | **y = 0.5 z + 0.5 v_deep** on labelled positions |
| MuZero Reanalyse (Schrittwieser et al., 2021) [recalled] | re-run the search with the latest network on OLD positions to refresh stale value / policy targets | none | the labeller re-searches old games (loop-sp6..9, r3-sp0) with the champion |
| KataGo (Wu, 2019) | z plus auxiliary and short-horizon value heads; playout-cap randomisation (most moves cheap, a few deep) | none | **cheap self-play, deep search only on sampled positions** (the corpus runs a 2-pass cap; the labels run 8 passes on a 6×6 matrix) |
| Gumbel MuZero (Danihelka et al., ICLR 2022) | the root's completed-Q mix; policy improvement guaranteed with few simulations | none | not used: our root is a matrix game, so the target is SLOWKING's game value, not a completed Q |
| ReBeL (Brown et al., NeurIPS 2020) | the value of a PUBLIC BELIEF STATE computed by CFR on the depth-limited subgame at each search; no outcome | the net takes the belief as input and outputs per-infostate values | not used as such: our hidden information is small (spreads, the back two) |
| Student of Games (Schmid et al., Sci. Adv. 2023) | counterfactual values from growing-tree CFR ("sound self-play") | belief-state input | same as ReBeL |
| DeepNash / R-NaD (Perolat et al., Science 2022) | model-free: regularised Nash dynamics, v-trace-style returns; no search at test | the net sees the player's own observation only | the fallback if search targets stall |

**Belief averaging, and what v1 does instead.** ReBeL and SoG feed the belief into the net. PokaiTrainer (our format, via
`…turn-search.md` §2.1) keeps a per-world value inside a Bayesian matrix game. v1 does the cheap version: the label is computed
on the TRUE battle (an "oracle" label), and the net is fed only the honest public view. With a squared or log loss the net then
regresses to E[v | public view], averaged over the hidden information as it is distributed in self-play (our team pool, the
flat spread). That is not XATU's posterior and it does nothing about strategy fusion; the search already averages over XATU's
worlds at play time, and the leaf is evaluated inside each world on its public view.

### 2. Set and attention encoders for Pokémon

| Work | Inputs | Size | Target | Lesson |
|---|---|---|---|---|
| VGC-Bench (Angliss et al., arXiv 2506.10326) | 12-Pokémon observation, learned move/item/ability embeddings | 3-layer transformer, 8 GPUs | PPO; BC then self-play (BCSP best) | per-entity tokens + learned embeddings work in doubles |
| Metamon (arXiv 2504.04395) | text tokens of the singles state | 15M–200M transformers | offline RL on 475k human battles, then self-play | **critic accuracy mattered more than the RL variant** |
| PokéChamp (Karten et al., ICML 2025) | LLM prompt | LLM | minimax with an LLM value | not affordable inside a CPU search |
| PokaiTrainer (arXiv 2608.29197, via `…turn-search.md`) | our exact format (Reg M-B doubles, open sheets, hidden spreads) | 5.4M-parameter transformer value net | BC on 122,804 replays, then self-play | **the value net stayed optimistic early: Brier 0.22 on turns 1–3 vs 0.10 from turn 8** |
| poke-env value/Q nets (hobby and course projects) [recalled] | hand features (HP, types, boosts) | small MLPs | outcome / TD | plateau at material-like play |

**What we took.** Per-mon tokens with learned id embeddings AND descriptive features (a new regulation has few games per
species), the engine's damage race as per-token relational facts (the part PORY never had), Deep Sets pooling as the baseline
and one attention block as the transformer arm, both antisymmetric. Width is capped by CPU inference inside the search, so the
transformer is d = 32 with one block — two orders of magnitude below PokaiTrainer's. Turns 1–3 are reported separately.

### 3. Small-compute AlphaZero reproductions: volume and overfitting

- **AlphaGo's value net overfit to correlated positions within a game** (Silver et al., Nature 2016 [recalled]): the fix was
  one position per game (30M positions from 30M games). PORYGON2 v0 showed exactly this — validation best after epoch 0, then
  memorised games. v1 therefore buys **many distinct games cheaply** (the 2-pass corpus) rather than many positions per game,
  labels only 1–2 positions per game deeply, keeps dropout and weight decay, and selects the epoch on validation.
- KataGo's playout-cap randomisation (above) is the throughput lever; Leela Zero and Minigo both reported value-head
  overfitting with a small replay window [recalled] — hence every earlier self-play directory on the release is kept.
- The Oracle z/q averaging result is the one we copied directly.

| Choice | Because of | Changed from the brief? |
|---|---|---|

| Deep labels only on 1–2 positions per game; the corpus is many cheap games | AlphaGo value-net overfitting; KataGo | the brief's "sampled positions" made concrete |
| Oracle (true-state) labels, honest inputs | ReBeL/SoG are too heavy; small hidden info | — |

## 4. Search-improved targets

`label.js`, flags in the preregistration: per game, one position drawn by a seeded hash plus the FIRST small endgame
(1v1, 2v1, 1v2). A normal position gets MILTANK from BOTH seats, k 6×6, 8 passes (288 playouts a seat), depth 0, gen5's
leaf and MAG/DODUO, on the TRUE battle; the label is the mean of side A's root value and 1 − side B's (median seat gap
0.013 over 3,819 positions). An endgame gets a recursive LP solve over every joint, 3 dice per cell, 2 turns (1 when the
root has > 20 joint pairs).

**5,466 labels: 3 workers for 3 h 06 min plus a 4th for 2 h 14 min** (one deadline, 13:15Z): 3,826 deep, 1,628 two-turn endgame solves with a leaf at the
horizon, **12 exact**. 0 errors, 0 search fallbacks, 0 replay mismatches. Median cost 2.9 s a label (deep 2.7 s, endgame
4.8 s). Labels landed on loop-sp9, loop-sp8, r2-sp1 and 1,629 positions of p2v1-c0; the deadline stopped the rest.

**Exact endgames are rare.** A 2-turn solve with 3 dice per cell is "exact" only when every branch ends the game; 12 of
1,640 did. The brief's "solved by exhaustive search" is therefore delivered as a 2-turn solve with gen5's leaf at the
horizon (`deep2`), exact up to the sampled dice where it terminates. A depth-3 1v1 solve costs ~110k engine steps and was
not affordable.

**The deeper search did not predict outcomes better than the cheap play-time root.** On the 5,458 labelled positions that
also have a recorded root: log-loss against the result 0.337 for the 8-pass label, 0.328 for the 2-pass root, 0.376 for gen5's
static value (Brier 0.107 / 0.104 / 0.123). Both searches carry information the static net lacks; the deeper one is not
closer to what happened, partly because the game that followed was played by the cheap search (the root is on-policy, the
deep label is not). Targets as pre-registered: human y = z; labelled self-play y = 0.5 z + 0.5 v_deep (exact: v_exact);
other self-play y = 0.75 z + 0.25 v_root.

## 9. Deviations and honest limits

- **The wide-run rule.** The SOLVER brief says a wide run is prepared and handed to Will. These runs (the corpus, the
  labels, the SPRTs) were launched on the coordinator's explicit instruction, at most 4 workers, BELOW_NORMAL, and never
  touched the ladder.
- **10× was not reached** (§3). **Exact endgame labels are 12** (§4). **The corpus is omniscient**: the positions are
  flat-spread; the leaf's facts are spread-agnostic by construction, so training and play see the same inputs.
- **Oracle labels, public inputs.** The net regresses to the value averaged over the hidden information as self-play
  distributes it, not over XATU's posterior; strategy fusion is untouched.
- **The human producer approximates** where the log is silent: a timer extended by an item, Pressure's PP, a failed shield
  counted as a shield.
- **A tie decided the architecture.** attn and sets differ by 2e-5 in combined validation loss; the pre-registered rule
  was followed. The human half of gate (a) separates them (attn clears, sets does not).
