## 2. The flaw: verified, not assumed

- **The list really did shrink with no document edit.**
  - `ea437935` and `a8ae54b0` both hold 2,258 keys. `b439bc2b` holds 2,256.
  - The two keys dropped are `docs/ABRA-whitepaper.md|451c61b952|112` and `|a1858747e6|181`.
  - `git diff ea437935 b439bc2b -- docs/ABRA-whitepaper.md` is empty.
  - `data/game-differential.json` went from `a24b99e7` to `06d0ced0`, and `data/mechanics-census.json` from
    `b9fd65b9` to `c322934d`, in that commit.
  - Today 112@185 is bound by `data/game-differential.json` and 181@2234 by `data/mechanics-census.json`. Both
    bindings are coincidence. The 181 sentence itself says the artifact "has been regenerated many times since".
- **The mechanism.** The census tested bound before it tested listed. Among listed figures, only those that
  landed in the grandfathered class were marked seen, and the test kept `[...GF].filter(k => seenGf.has(k))`.
  So a listed figure bound for one run was dropped, and the next regeneration left it red.
- **Real-data reproduction** (read-only; the census with the two artifacts swapped between the `ea437935` and
  `cb552cc3` blobs):

  | step | old rule (`ea437935`) | new rule |
  |---|---|---|
  | bootstrap artifacts | 112, 181 grandfathered | same |
  | regenerated artifacts, green run | **retires 2** | retires 0 (2 dormant) |
  | artifacts move again | 181 **UNBOUND — RED** (112 lands in predates) | 112, 181 grandfathered — green |

- **How often it bites.** I read `data/meta-usage.json` at each of its last 10 ingests, with `docs/MODELS.md`
  as at HEAD. **2 of 9 ingest steps would have turned the gate red on their own**, both on 925: `73bc0143`
  (2026-09-09) and `43ef7386` (today). The value drifted in and out of the file between those two.

## 3. The fix (`engine/docs_scan.js`, `tests/test-docs-current.js`)

- **Retirement.** `untraceableCensus` now also returns `grandfathered_dormant` and `grandfathered_bound`:
  - `grandfathered_dormant`: listed keys bound this run by a file on disk.
  - `grandfathered_bound`: listed keys bound by the entry the block names, or by a commit-pinned blob.

  `retainGrandfathered(list, census)` keeps a key that is seen or dormant, and drops the rest. The gate writes
  through that function, and the ratchet counts dormant keys as current, not retired. The list still never
  grows.
- **Commit-pinned citation.**
  - `` `<hash>:data/x.json` `` binds the whole blob. `` `<hash>:data/x.json:field` `` binds that field. Both are
    read with `git show` through the same `parseArtifactText` the disk reader now uses.
  - A hash that is not an ancestor of HEAD is refused out loud and binds nothing. The check is shown on
    `ea437935`, which resolves locally but was rebased away.
  - One `PIN_BEHIND` lookbehind in `citationsIn`, `FIELD_CITE_RE` and the census's bare-mention test stops the
    pinned form reading as a citation of today's file.
  - Effect across every living document plus the notes: exactly one cited-artifact set changed.
    `docs/RUNNING-NOTES.md` no longer cites `data/pory-eval.json`; it only ever mentioned it pinned at
    `44e0fb0`. The citation-mismatch list did not move.
- **Why entry and pinned bindings retire but disk bindings do not.** A disk binding lasts until the next
  regeneration. The other two are written by a person and are not regenerated.
- **Red demonstration, pinned in both directions** (the shipping `traceProof`, 23 cases; `retain` is injectable
  so that other rules can be run against the same cases):

  | rule | result |
  |---|---|
  | shipped in `ea437935` | **22/23** — broken: `a-grandfathered-figure-an-artifact-happens-to-hold-keeps-its-place` (got unbound) |
  | "keep while the sentence is unchanged" | **21/23** — broken: both controls (an entry and a pin that the document wrote must retire) |
  | new (shipping) | **23/23** |

  Four pin cases were added as well: a pinned field binds its value; it binds nothing else in its blob; a
  pinned blob is not the file on disk; a commit outside this history binds nothing. With the two proof
  helpers above, the bound-trace demonstration goes from 16 to 23 cases.
