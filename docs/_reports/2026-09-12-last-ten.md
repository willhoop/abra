### 4. ROADMAP #608 — the quiet set is fixed at the predicate, and it opens three rows at once

`QUIET`'s predicate is `typeof a[k] === 'function'`, so it **cannot see a boolean**. Asked of
Champions: `shellarmor` and `battlearmor` carry `onCriticalHit = false`, a DATA field, and both
therefore sat in the quiet set — which is how the swapper came to lend a CRIT BLOCKER.

The guard that went in this morning refused the whole `bottom-tie-first` CORNER because of that one
ability. **That is a bigger refusal than the fact supports**, and #608's own refinement says so: the
fix is a `quietAsControl(ability, arm)` DISTINCT from `moveQuietAbilities(arm)`. It is now written:

```
crit armour (2) — quiet only because `onCriticalHit` is the BOOLEAN false: battlearmor, shellarmor
  quiet AS A CONTROL on top-tie-first     ballfetch, battlearmor, corrosion, dancer, earlybird,
                                          honeygather, runaway, shellarmor
                                          -> swapper Goodra-Hisui lending Shell Armor
  quiet AS A CONTROL on bottom-tie-first  ballfetch, corrosion, dancer, earlybird, honeygather,
                                          runaway
                                          -> swapper Glimmora lending Corrosion
```

The set is DERIVED off `onCriticalHit === false`, never off a name, and printed by `--rules`.

**BLAST RADIUS MEASURED BEFORE THE CHANGE, NOT ARGUED.** On `top-tie-first` the derivation is
byte-identical — Shell Armor still qualifies and Goodra-Hisui is still the bulkiest. On
`bottom-tie-first` **no standing row used the Skill Swap control at all**, because the guard refused
every one; read off `git show HEAD:data/roster.abilities.json`, the nine bottom-arm rows
(`battlearmor`, `immunity`, `insomnia`, `limber`, `magmaarmor`, `shellarmor`, `skilllink`, `stench`,
`vitalspirit`) every one carried a SHEET control. So the change is strictly additive.

Three supporting pieces, each of which the run forced:

- **`swapControlWorks(arm)` is now per-arm.** A single cached proof would certify one lent ability and
  be quoted for another. Keyed on the arm and re-played with the body that arm will actually use
  (`38 leaves in Showdown and 38 here, lending Corrosion off Glimmora on bottom-tie-first`).
- **THE PROVISIONAL GOES INTO THE CACHE BEFORE THE PROOF PLAYS.** The single-variable version this
  replaced was assigned at the top as a re-entrancy guard — the proof builds a real scenario through
  `abilityScenario`, which can ask this function again — and moving the assignment to the end recursed
  until the stack ran out. Every row of `ability/refuses-one-status` read *"the shape rule threw:
  Maximum call stack size exceeded"* on the first run after the change. Caught in one run, fixed, and

- **`swapperFor(arm, avoid)` keeps the swapper off a species the rule already wrote onto side A.**
  `isSwapper()` only knows the top-arm swapper, and two bodies of one species collapse into ONE party
  row — the party collapse this morning's pass found. The bottom-arm swapper is a different species,

**A SIDE EFFECT WORTH STATING: four standing greens got a BETTER control.** `immunity`, `insomnia`,
