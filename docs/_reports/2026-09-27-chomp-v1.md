## 3. Gate (a) — read once (`solver/chomp/v1/model/chomp1.metrics.json`)

Selected arm **`lin`** (VAL log-loss 0.6533 vs `mlp` 0.6550); baseline arm `lin` (0.6742).

| set | n | scorer LL | baseline LL | Δ [95% cluster bootstrap] |
|---|---|---|---|---|
| T1 targeted TEST pairs | 2,768 (173 pairs) | 0.6474 | 0.6687 | **−0.0213 [−0.0323, −0.0108]** |
| T2 corpus test fold | 351 | 0.6741 | 0.6863 | −0.0122 [−0.0335, +0.0106] |
| T3 human TEST (reported, not gated) | 188 | 0.6924 | 0.6902 | +0.0022 [−0.0101, +0.0147] |
| **T1 + T2 pooled (the gate)** | 3,119 (476) | | | **−0.0203 [−0.0309, −0.0108] → PASS** |

Learned temperatures: τ_selfplay 0.93, τ_human 0.32 (targeted fixed at 1). **The human set carries no measurable bring
signal** for this scorer; its gain is on simulated play.

**The first break was wrong and is reported as such.** Shuffling the labels of BOTH the scorer and the baseline still
"passed" (Δ −0.0024, CI below 0): two noise models compared on one set. The break was corrected to shuffle the
scorer's labels only (the question: a scorer that learned nothing must fail) and then went red (Δ +0.0156). The real
run's code path is identical under both versions (the break is off). Take the lesson: an effect of ~0.002 in this
comparison is not evidence; −0.020 is ten times it.

## 4. In-table report (no game played; `solver/out/chomp/v1/report/table_report.json`)

On the 173 TEST pairs × 2 chairs: support 2.0 options on average (p90 3), solve 18 ms mean (p90 21 ms, 8,100 cells).
Options span 0.28 in win chance against a uniform opponent (v0's PORYGON2 table could not tell a human option from a
random one). The mix's top option is the human-modal option on 3.2% of sides and the human's own on 2.3%: **CHOMP v1
disagrees with humans almost everywhere**, and in its own table the modal option's regret is 0.123 (human's 0.127).
Whether that disagreement is insight or model error is exactly what gate (b) must answer.

**Bo3 adjustment** (opponent previous = the recorded human four/leads): gain against the opponent model q is +0.0064 after
they won and +0.0030 after they lost, for an exploitability of 0.010 and 0.008 in the table. Small by construction
(λ = 0.5). No bo3 arena exists; this is not a play-strength claim.
