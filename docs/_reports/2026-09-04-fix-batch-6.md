## 2. FIX 1 — THE AUTHORITY'S STEP 4 RUNS WHEN A SUBSTITUTE ATE THE HIT, AND THE BACKSTOP DID NOT FLUSH IT

**Probe:** `tests/probe_selfdrop_through_sub.js`. **Knob:** `MEDI_SELFPAY_SKIPPED_ON_SUB=1`.

**Authority.** `data/moves.ts:18335-18367`, `substitute.condition.onTryPrimaryHit`, ends
`return this.HIT_SUBSTITUTE;` on BOTH arms — the doll that broke and the doll that stood. Then
`sim/battle-actions.ts:1054-1069`:

```
if (damage[i] === this.battle.HIT_SUBSTITUTE) { damage[i] = true; targets[i] = null; }   // NULL, not false
if (!damage[i]) targets[i] = false;                                                      // damage[i] is true
```

and `:1096` / `:1317-1325`:

```
if (moveData.self && !move.selfDropped) this.selfDrops(targets, pokemon, move, moveData, isSecondary);
selfDrops(...) { for (const target of targets) { if (target === false) continue;   // `null` is NOT `false`
                   ... this.moveHit(source, source, move, moveData.self, isSecondary, true); } }
```

Champions overrides neither `closecombat` nor `substitute`.

**What this engine did.** WIRE 42's substitute road ends `R.out = true; return;`, and the step driver
is `for (const _step of _STEPS) for (const R of _rows) { if (R.out) continue; _step(R); }`. The file
already knew this shape — the backstop below the driver flushes `_stepAfterHitField` and `_stepUpdate`
for exactly that reason, and its own comment names `out` + `_reached > 0` as the substitute case.
**`_stepSelfPay` was simply not in the flush.**

**RED FIRST**, staged head-to-head against the official simulator on a derived fixture (Sneasler's
Close Combat into a Snorlax that put a doll up; both engines read on their own state):

```
NO DOLL   medi boosts {def:-1, spd:-1}   sd boosts {def:-1, spd:-1}     <- agreed BEFORE and after
DOLL UP   medi boosts {def: 0, spd: 0}   sd boosts {def:-1, spd:-1}     <- the defect
          doll 58 in both, fate {broke:1} in both
FAIL  TEST     — through the doll, the attacker's own stat table matches the authority
FAIL  CONTROL — and no stat OUTSIDE the move's declared table moved
FAIL  COUNTER  selfPayFlushed=0
```

**AFTER:** `{def:-1, spd:-1}` in both, `selfPayFlushed=2`, knob child exits 1. Five controls green on
both arms: the no-doll arm; the doll's ANNOUNCED fate (`-end` vs `-activate`, read off each engine's
own log rather than off its HP, because the slower target re-clicks Substitute on the same turn and
the HP reading cannot tell a break from a survive); no stat outside the declared table; a click
REFUSED by Protect pays nothing in either engine; and the doll behind that shield is never reached.

**THE GATE IS `_reached > 0`, AND IT IS THE AUTHORITY'S OWN.** A total MISS never reaches
`spreadMoveHit` at all — `hitStepAccuracy` empties the target list above it — so `selfDrops` is not
merely refused on a miss, it is not called. Flushing unconditionally would have let the step's
recharge arm mark `_rechargeArmed` on a missed Hyper Beam and silently disarm WIRE 43's backstop.

**THE RECHARGE HALF DID NOT MOVE, AND THE PROBE SAYS SO.** A `mustrecharge` move through a doll armed
the recharge in both engines BEFORE this fix too — WIRE 43's block below the step list was already
catching it. Arm 7 is green on both arms of the knob, deliberately: it says the change is the stat
table and nothing else.

## 3. FIX 2 — A SLEEP CHOSEN INSIDE THE HANDLER IS ANNOUNCED BARE

**Probe:** `tests/probe_direclaw_attribution.js`. **Knob:** `MEDI_PROCEDURAL_STATUS_NAMES_MOVE=1`.

**Authority.** `data/mods/champions/conditions.ts` `slp.onStart` — the format OVERRIDES this
condition, so `data/conditions.ts` is the wrong file and the two differ (`sample([2,3,3])` against
`random(2,5)`). The line names a move only when `sourceEffect.effectType === 'Move'`.

Two shapes reach `setStatus`:

- a **declared** status — `runMoveEffects` calls `target.setStatus(moveData.status, pokemon, move, false)`,
  the move is passed, the line NAMES it;
- a status **chosen in the handler** — `data/mods/champions/moves.ts:191-208`, direclaw's secondary
  calls `target.trySetStatus(status, source)` with **no third argument**, so `setStatus` falls back to
  `sourceEffect = this.battle.effect`, which inside `singleEvent('Hit', <the secondary>, ...)` is the
  ANONYMOUS secondary object `{ chance: 30, onHit }`. Neither branch. The bare arm.

**MEASURED IN THE AUTHORITY, one staged turn per move, target Milotic:**

```
sleeppowder (primary status)   |-status|p2a: Milotic|slp|[from] move: Sleep Powder
hypnosis    (primary status)   |-status|p2a: Milotic|slp|[from] move: Hypnosis
direclaw    (proceduralStatus) |-status|p2a: Milotic|slp            <- bare
yawn        (a condition)      |-status|p2a: Milotic|slp            <- bare
```

That is the shape of the TAG, not a property of one move: `proceduralStatus` is derived from exactly
this — a secondary with a chance, no `status`, and a `sample([...])` in its own `onHit`. Both legal
members are printed by the probe (`direclaw` 5,416 uses, `triattack` 7).

**RED FIRST:** `medi |-status|p2a:hippowdon|slp|[from]move:direclaw` against the authority's bare
line. **AFTER:** identical bare lines, `proceduralStatusApplied=46 slpUnattributedAnonEffect=10`, knob
child exits 1. Four controls green on both arms: a DECLARED sleep move still names itself in both
engines; the same click's `psn` and `par` lines are bare in both; and the sleep CLOCK histogram is
the same model in both — **that control is what refutes the "one turn long" diagnosis, inside the
probe, permanently.**

**DECLARED REMAINDER, WRITTEN INTO THE PROBE HEADER:** the Champions override ALSO adds a refusal this
engine does not carry — `if (target.status) { add('-fail', target, status===target.status ? status :
undefined); return; }`, measured in the authority as `|-fail|p2a: Milotic|slp` and `|-fail|p2a: Milotic`.
It is Dire-Claw-only ("This seems to only happen with Dire Claw" — the mod's own comment), so wiring it
needs a new `proceduralStatus` param derived from the handler source rather than a move name, and
**`engine/tag_dex.js` exhausts the heap under `tools/lownode.cmd`** (see OWED), so `data/tags.json`
could not be regenerated in this pass. Owed and unprobed.
