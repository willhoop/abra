## Method notes, because two of the rules here are easy to break silently

**Line endings were measured per file rather than assumed.** All eight files are **100% CRLF** (0 bare
LF in every one). Insertion was done with a splice that finds the anchor line, reads the terminator
*that line actually carries*, and rebuilds only the inserted span with it — every other byte in each
file is untouched. Verified after each write: CRLF counts rose by exactly the number of lines added
and bare-LF stayed at 0 in all eight files.

**No `<!-- GENERATED -->` block was hand-edited.** The MEASURE, ENGINE, OPS and SEARCH generated
blocks *do* show a diff in the working tree — `_stamped 2026-09-04 21:41_` → `_stamped 2026-09-04
23:52_`, plus a provenance count and a newest-engine-source line. **That is not this pass.** It is the
output of a `status.js --write` run at 23:52 that predates this session; `docs/OPS.md` and
`docs/SEARCH.md` carry the same stamp change and were never opened here. Every removed line in this
pass's diff is one of the six version headers; the complete removed-line list was checked to confirm
it.

**Every figure was checked against the citation rule before it was written, not after.** Each block
was drafted to a scratch file and run through `engine/docs_scan.js`'s own `paragraphs`,
`citationsIn`, `figuresInText`, `artifactNumbers` and `artifactHas` — the shipping functions, not a
re-implementation — so that a figure in a block naming a top-level `data/*.json` had to be present in
that file, and a figure in an uncited block had to be present in some artifact or in the CHANGELOG.
All eight drafts came back CLEAN before insertion. Backtick parity was checked on all 167 added
lines: 0 lines with an odd count.

**No number was authored.** Every figure in every new block is one written in plain prose in the
`## [5.255.0]` changelog entry. Two phrasings that would have introduced arithmetic of my own were
removed before they shipped: a heading computing "nineteen leaves" from 56 − 37, and a WIRE number
quoted next to Poison Touch.
